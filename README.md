# Adarsh R — Developer Portfolio

Responsive static portfolio built with HTML, CSS, and vanilla JavaScript. It will later be packaged with Docker/Nginx and deployed to Microsoft Azure.

## Run locally on Windows

Open `index.html` in a modern browser, or open PowerShell in this folder and run:

```powershell
py -m http.server 5500
```

Visit `http://localhost:5500`.

## Before publishing

- Replace `hello@example.com` in `index.html` with your preferred contact email, or remove the contact link.
- Update project descriptions and skills to reflect your actual work.
- Google Fonts are loaded from an external CDN; fallback fonts are included.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive styling, red/yellow/black palette, hover effects, and scroll transitions
- `script.js` — mobile navigation, current year, cursor glow, and scroll reveal behavior
